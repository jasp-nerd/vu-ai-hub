# VU AI Student Hub

A website and resource collection for AI students at VU Amsterdam. Built with React + Vite.

The site includes course info, study tips, quizzes, and links to study materials.

## Study Resources

The `vu-ai-resources/` folder contains free study materials (summaries, formula sheets, crash course notes, exam prep, etc.) for courses in the BSc AI programme. See the [resource README](vu-ai-resources/README.md) for the full list.

## Development

```bash
npm install
npm run dev
```

Course materials remain the property of their respective authors at VU Amsterdam. If you'd like something removed, open an issue.
