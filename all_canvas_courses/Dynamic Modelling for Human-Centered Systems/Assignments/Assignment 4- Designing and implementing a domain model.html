In this assignment, you will design a domain model based on an existing text, and partly implement it using the L2 software. You can use the slides of lecture 7 as example of this process.

This assignment is implemented as a Jupyter notebook. Please move Assignment4.ipynb to your L2 folder and load it in Jupyter. You can then add the answers to the questions and complete the implementation of the model. The final result should be a running model that results in visualizations of the simulation.

The notebook asks you to:

  1. Create a table in which you list all relevant concepts that you will use in your model. (20 points) 
  1. Create a graphical representation of the relations between all concepts.  (20 points)
  1. Write a set of semi-formal rules that specify the relations between the concepts in more detail.  (20 points)
  1. Implement the domain model specified above using the L2-Python software and make sure that it runs correctly.  (40 points)
