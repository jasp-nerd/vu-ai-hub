Hi!

I had a Marbel problem (where the agent just wouldn't work) earlier, and noticed that a lot of people on macOS seem to run into this kind of issue. Not sure if this will work for everyone, but it fixed it for me.

This was the error I was getting:

A fatal error has been detected by the Java Runtime Environment:
SIGBUS(0xa)

JRE version:OpenJDKRuntimeEnvironmentTemurin-11.0.29+7
Java VM:OpenJDK64-BitServerVMTemurin-11.0.29+7

Problematic frame:
[libgmp.10.dylib+0x1c084]_gmpn_add_n+0x8c

ThecrashhappenedoutsidetheJavaVirtualMachineinnativecode.

 

First, I ran this on my terminal (before this step, you need to stop the marbel agent and the server):


mv"$HOME/Library/Application Support/swilibs/1.0.1-SNAPSHOT/mac/libgmp.10.dylib" \
"$HOME/Library/Application Support/swilibs/1.0.1-SNAPSHOT/mac/libgmp.10.dylib.backup"

 

After that, I linked the Homebrew version of GMP:


ln -s /opt/homebrew/opt/gmp/lib/libgmp.10.dylib \
"$HOME/Library/Application Support/swilibs/1.0.1-SNAPSHOT/mac/libgmp.10.dylib"
