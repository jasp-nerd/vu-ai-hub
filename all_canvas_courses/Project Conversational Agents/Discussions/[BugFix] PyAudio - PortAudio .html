Hi All,

For some of you (typically on MacOS) there has been installation issues which manifest in a variety of ways; from microphone issues to server issues.

This is caused by attempting to fix the "portaudio not installed" error using conda (conda-forge to be exact).

The "better" fix is to follow the normal installation procedure without ever using conda, which breaks the install.

To solve the port-audio installation issues, instead of using conda, you should replace all scripts that use pyaudio (that contain "import pyaudio"); there should be 3 such files in the whole project.

I've attached a zip files which contains:

.
├── desktop_microphone.py
├── desktop_speakers.py
├── desktop_text_to_speech.py
└── fix.sh

The python files (.py) are "sounddevice" alternatives which you should copy, the "fix.sh" copies the files automatically (if you copy the unzipped folder into your project and run the script it will do the overwrite itself).

KEEP IN MIND THAT IF YOU PUSH OR PULL THESE FILES THEY WILL CHANGE FOR YOUR WHOLE TEAM: IF YOU WANT TO AVOID THAT EITHER ADD THEM TO GITIGNORE OR AGREE WITH YOUR TEAM TO USE THESE NEW SCRIPTS (THEY WILL HAVE TO RUN PIP INSTALL SOUNDDEVICE FOR THE LATTER).
