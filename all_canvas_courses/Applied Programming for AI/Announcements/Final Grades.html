💯 Final grade

  • The column final_grade_adj contains your final grade. This grade is calculated as explained on Canvas, using the following formula:  

final_grade_adj = (Communication Backend-frontend (Group) * 10%) + Individual Frontend * 15%) +  (Project Backend & Tests * 35% ) + (GenAI Report * 10% ) + (Participation * 20%) + (Final Demo Session* 10%)

🫣 If you failed the coding interview you obtained 5.0 in this column, which will be translated into a NVD on VUNet.
