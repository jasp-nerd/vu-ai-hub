Syllabus — Applied Programming for AI

📌 Introduction

Welcome to the Applied Programming for AI course; this course is designed to equip you with the skills needed to create dynamic and interactive web applications that interact with APIs (Application Programming Interfaces) from scratch. In this project-based course, you will delve into the world of both frontend and backend development, gaining a general understanding of web technologies and popular programming languages like Python, CSS, HTML or JavaScript. Moreover, you will be practicing with GenAI tools for coding, where you will experiment on how to introduce their usage into an existing manually created software project.

📋 Methodology

🥅 Course Goal

The goal of this course is to obtain skills in designing and implementing an interactive web application and data processing pipeline. Students will engage in the creation of both components, connecting them through a REST API. This course covers the basics of frontend development with HTML, CSS and JavaScript, backend development in Python, version control systems (VCS) (e.g., Git) and places a strong emphasis on team work.

In this edition of the course, students will experiment and collaborate with generative AI tools for coding. Moreover, we will be adopting a test-driven development methodology, where we will first define the requirements, implement the tests that should satisfy those requirements, and then the final implementation.

By the end of the course, students will have gained practical experience in web development, working in groups, collaborating with a generative AI tool, and acquired the ability to work effectively in a real-life work environment.

💯 Assessment

Given the nature of this course, students will be evaluated in multiple levels. Students will be graded on individual and team work as well. It is possible that the final grade of team members differs.

The final grade for this course consists of the following parts:

  • Project Proposal → Pass/fail
  • Implementation (60%)
    • Frontend (individual) (15%)
    • Backend (35%)
    • Communication backend-frontend (10%)
  • Degree of participation (individual) (20%)
    • Attendance (10%)
    • Git Activity and contribution to the project (10%)
  • Generative AI Report (individual) → 10%
  • Final demo presentation (team) → 10%
  • Coding interview (individual)  → Pass/fail

👀 To obtain a passing grade for the course, you must pass the coding interview.


Each week, you have deliverables that you must implement and push to your repository. If you commit and push your contributions later, this will have an impact on your grade.

🎙️ Coding Interview

This is an essential component of this course. Each week, you have partial deliverables that you must submit via Canvas and GitHub. If you do not push your contributions in time, you will automatically get a fail for the coding interview. 

Important: There is no resit for the coding interview.
