Practical assignment 1 (Manipulating formal systems: PL and Knowledge Graphs)

Due: 9/8/2025, 1:00:00 PM

For this practical assignment you will have to do some (relatively simple) Python programming to manipulate Propositional Logic (to get used to working with simple symbolic languages), and then with Simple Knowledge Graphs (to get a get a hands on impression on what really happens in the state-of-the art tools we will use later for similar purposes.

There will be 6 tasks:

  1. Task 1: Complete a given procedure infix that transforms the formula into Infix notation, i.e., the operator "sits" between the two arguments.
  2. Task 2: Write a procedure evaluate that calculates the value of the formula for the following assignment.
  3. Task 3: Write a procedure tautology that calculates whether a given formula (with maximally three variables P,Q and R) is a tautology
  4. Task 4: Write procedures as_ntriples to transform the Knowledge Graphs into simple-n-triples.
  5. Task 5: Write a procedure tripleEntailed to evaluate whether a Triple (s p o) is entailed by your Knowledge Graph
  6. Task 6: Write a procedure graphEntailed to evaluate whether one Knowledge Graph is entailed by another Knowledge Graph

Don't worry, this sounds more difficult than it is.
