Practical assignment 3 (Quering and Inferencing over Linked Data)

Due: 9/23/2025, 1:00:00 PM

For this practical assignment, there will be 4 tasks: 

- In task 1, we will integrate local RDF knowledge graphs with external data

- In task 2, we will implement ourselves some of the RDFS inference rules. You can have a look at the lecture slides for (slightly differently numbered) rules

- In task 3, we will create our first RDFS knowledge graph. We will make use of the rules implemented in task 2 to infer implicit knowledge in our knowledge graph. 

- In task 4, we will start working with triple stores, and in particular with the GraphDB triples store. You can check this short GraphDB tutorial to learn how to install and work with GraphDB for completing this task.

 

Follow the Learning Activity to make sure you understand the tasks. Please watch the lectures on  SPARQL and RDFS.
