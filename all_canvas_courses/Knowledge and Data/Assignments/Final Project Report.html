Final Project Report

Final Project Report

Due: 10/27/2025, 11:59:00 PM

Hand in a final version of the project as a report about the analysis. Building on the Milestone content, this should be the completed project and document. For the requirements of the project document, we refer you to the final project template: https://tinyurl.com/kandd24projecttemplate 

To summarize:

  • A report of 8-12 pages (approximately) and ±4000-6000 words
  • A Knowledge Graph in the form of two Turtle files (one file = ontology, one file = instances)
  • All the necessary Jupyter notebook files + a README file containing instructions on how to run the notebook

How to submit your project?

  1. Add the report (PDF) + ontology (TURTLE) + instances (TURTLE) + all the necessary notebook files into one directory
  2. Name the directory GROUP_ID (e.g. GROUP_1)
  3. Compress the directory GROUP_ID into one ZIP file (e.g. GROUP_1.zip)
  4. Upload the ZIP file to Canvas (to Final Project Report)
  5. Add the full names of the group members in the text entry box when uploading the ZIP file to Canvas
