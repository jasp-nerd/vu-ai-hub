Dear all. 

Please note the following about the coding interviews:

  • You can only register for a coding interview after you have received the grade for an assignment. So the first coding interviews can only be scheduled for after the publication of the grades this Friday.
  • You can only register for a coding interview in the online TA sheet (https://tinyurl.com/kandd25onlineTA) in a block where a TA is actually present (color-coded). Do not schedule it in a 'white' block.
