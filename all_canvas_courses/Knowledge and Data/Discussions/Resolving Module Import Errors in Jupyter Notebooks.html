Resolving Module Import Errors in Jupyter Notebooks

Hello everyone,

Some of you have encountered issues with module imports when running your assignment 1 Jupyter notebooks. The main cause of this problem seems to be launching Jupyter Notebook from the Anaconda Navigator. Here’s a simple solution to help you avoid these issues by using JupyterLab instead.

Solution: Use JupyterLab Instead of Anaconda Navigator

1. Download the Assignment Zip File:

  • Download the zip file containing the assignment to your preferred location (e.g., ~/Downloads).

2. Unpack the Zip File:

  • Extract the contents of the zip file. This will create a folder with all the necessary files.

3. Open the Notebook Using JupyterLab:

  • Open your terminal and navigate to the extracted folder:
    cd ~/Downloads/<assignment_folder>
    jupyter-lab
  • In JupyterLab, use the file tree on the left sidebar to navigate to the notebook and open it. This ensures that the notebook is executed in the correct directory, avoiding module import errors.

By following these steps and using JupyterLab instead of the Anaconda Navigator, you should be able to avoid module import errors and run your code smoothly.
