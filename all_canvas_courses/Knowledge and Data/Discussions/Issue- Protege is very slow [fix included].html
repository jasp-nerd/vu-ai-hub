Issue: Protege is very slow [fix included]

Author: A. Coşar (Adrian)

Posted: 9/24/2025, 6:52:14 PM

For anyone experiencing this issue, I recommend checking to see if Protege is trying to connect to git. It can be easily seen in the bottom left of the app, or, alternatively, when running the bat file, in the command line. Simply deleting the .git folder from my machine fixed this issue.
