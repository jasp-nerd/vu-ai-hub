To Know For The Exam

General comments:

  • You don’t need to know the formulas, means, and variances of special distributions (e.g. binomial and exponential); If you need these, they will be provided on the formula sheet.
  • You don’t need to know the formulas for confidence intervals and test-statistics; these too will provided on the formula sheet.
  • Quantiles of various distributions (e.g. normal, t, chi-squared) that you might need for the construction of confidence intervals will also be provided on the formula sheet.
  • You don’t need to know Chebyshev’s inequality.
  • A simple (i.e., non-graphical) calculator is allowed.

Material (from the textbook):

Section 1 (except 1.3.5), Section 3 (except the hypergeometric distribution), Section 4, Section 4.1 and 4.2 (except the method of transformations, memoryless property of the exponential distribution, and Section 4.2.4 and 4.2.5), Section 7.1 (except continuity correction), Section 8.1 (except order statistics), 8.2 (except 8.2.4), Section 8.3, Section 8.4 (except Type II errors, relation to confidence intervals, and Section 8.4.5)

The Midterm Exam covers Section 1, 3 (and probably a part of Section 4, depending on how far we get). The Final Exam covers all content.

1 Basic Concepts

 1.2 Review of set theory

  • Know the definitions and basic properties of the following concepts: set, subset, empty set, universal set, union, intersection, complement, difference, cardinality, mutually exclusive (disjoint), partition, Cartesian product, cardinality, countable, uncountable, domain, co-domain and range (of a function), de Morgan’s laws, distributive laws, inclusion-exclusion principle for two and three sets.
  • Determine sets involving unions, intersections, complements, differences, and cardinality (e.g. Example 1.4; Section 1.5, Exercise 1, 2, 5, 6).
  • Able to apply the inclusion-exclusion principle for two and three sets to solve simple problems (e.g. Example 1.5).
  • Determine the range and codomain of functions (e.g. Section 1.5, Exercise 12).
  • Determine is a given set is countable or uncountable (e.g. Section 1.2.5, Problem 4; Section 1.5, Exercise 7).

1.3 Random experiments and probabilities

  •  Know the definitions and basic properties of the following concepts: random experiment, probability (measure), discrete probability model, geometric series, inclusion-exclusion principle for two and three events.
  • Determine the sample space of simple experiments (e.g. Example 1.7, Section 1.3.6, Problem 2).
  • Calculate probabilities in simple situations (e.g. Example 1.11, 1.12; Section 1.3.6, Problem 3, 4; Section 1.5, Exercise 13, 14, 16, 17, 18, 22).

1.4 Conditional probability

  •  Know the definitions and basic properties of the following concepts: conditional probability, independence (of events), law of total probability, Bayes’ rule.
  • Calculate conditional probabilities in simple situations (e.g. Example 1.15, 1.17, 1.18, 1.19, 1.24, 1.25, 1.26; Section 1.4.5, Problem 1, 2; Section 1.5, Problem 28, 35).
  • Determine if given random variables are independent (e.g. Example 1.20; Section 1.5, Problem 25, 30, 34).
  • Apply the concept of independence to solve simple problems (e.g. Example 1.22; Section 1.5, Problem 28).

3 Discrete Random Variables  

 3.1 Basic concepts

  •  Know the definitions and basic properties of the following concepts: random variable (continuous/discrete), probability mass function (PMF), independence (of random variables).
  • Calculate probabilities involving discrete random variables, given their PMF (e.g. Section 3.1.6, Problem 1, 2, 6).
  • Determine the PMF of (functions of) discrete random variables (e.g. Section 3.1.6, Problem 3, 4, 8; Section 3.2.5, Problem 3).

 3.2 More about Discrete Random Variables

  •  Know the definitions and basic properties of the following concepts: cumulative distribution function (CDF), expectation and variance, LOTUS.
  • Determine the CDF of (functions of) discrete random variables (e.g. Section 3.2.5, Problem 1).
  • Calculate expected values and variances of (functions of) discrete random variables (e.g. Section 3.2.5, Problem 2, 4, 6, 8, 9).

4 Continuous and Mixed Random Variables  

 4.1 Continuous Random Variables and their Distributions

  •  Know the definitions and basic properties of the following concepts: continuous random variable, probability density function (PDF), range, expected value and variance.
  • Calculate expected values and variances of (functions of) continuous random variables (e.g. Section 4.1.4 Problem 1, 3 and Section 4.4 Problem 1, 2, 4, 5).
  • Calculate probabilities involving continuous random variables (e.g. Section 4.1.4 Problem 1, 3 and Section 4.4 Problem 2, 8, 9, 11)
  • Determine the PDF and CDF of continuous random variables (e.g. Section 4.1.4 Problem 2 and Section 4.4, Problem 1, 2, 4, 5).

 4.2 Special distributions

  •  Know the definitions and basic properties of the following concepts: normal (Gaussian) distribution.
  • Calculate probabilities involving exponential and normal random variables (e.g. Section 4.2.6 Problem 3, 4, 5 and Section 4.4, Problem 8, 9, 11).

7 Limit Theorems and Convergence of Random Variables

  •  Know the definitions and basic properties of the following concepts: weak law of large numbers (WLLN), central limit theorem (CLT).
  • Use the CLT to approximate probabilities (e.g. Section 7.3, Problem 2, 3, 5, 6, 7).

 8 Statistical Inference I: Classical Methods

 8.1 Introduction

 Know the definitions and basic properties of the following concepts: random sample, sample mean.

 8.2 Point Estimation

  •  Know the definitions and basic properties of the following concepts: (point) estimator, bias, unbiased estimator, mean squared error (MSE), consistent estimator, sample variance and standard deviation, likelihood function, maximum likelihood estimator (MLE).
  • Calculate bias and MSE of an estimator and determine if an estimator is unbiased (e.g. Section 8.6 Problem 2, 3).
  • Calculate the (log) likelihood function from the PMF or PDF of a random variable (e.g. Section 8.6 Problem 4, 5).
  • Find maximum likelihood estimators for simple models (e.g. Section 8.6, Problem 7, 8).

8.3 Interval Estimation

  •  Know the definitions and basic properties of the following concepts: interval estimator, confidence interval, confidence level, pivot.
  • Construct confidence intervals for the mean, proportion, and variance, based on observed sample quantities (e.g. sample mean and variance) (e.g. Section 8.6, Problem 11, 12, 13, 14).

 8.4 Hypothesis Testing

  •  Know the definitions and basic properties of the following concepts: null and alternative hypothesis, test-statistic, acceptance and rejection region, Type I and Type II error, p-value.
  • Choose an appropriate test-statistic to test a given hypothesis about the mean, carry out the test, calculate the p-value, and draw a conclusion (e.g. Section 8.6 Problem 15, 16, 17, 18, 19, 20).
