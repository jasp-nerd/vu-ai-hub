Running Mac/Linux Commands on Windows

Posted: 9/23/2024, 12:38:07 PM

For students who have a Windows computer but would prefer to use Mac/Linux commands instead of the Windows cmd/powershell ones, there are a few options that you can use to emulate a bash/zsh terminal!https://gitforwindows.org/ is a tool that allows you to use bash on windows and also gives you access to git, the industry standard version control software that you will use to collaborate on code later in your studies. Simply install, then right click in a chosen folder or on desktop and click 'git bash here' from the dropdown. Alternatively, you can use Windows Subsystem for Linux, the tool offered by Microsoft which allows you to run a version of Ubuntu on your Windows computer with minimal effort. Instructions on how to use that here: https://learn.microsoft.com/en-us/windows/wsl/install. This is a little more involved, but will allow you to make use of other benefits of Linux without installing a separate operating system!

Hope this helps :)
