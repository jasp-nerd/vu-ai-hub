  • Create a Directory:

    • Use the command mkdir to create a directory named mydirectory.

  • Create Text Files:

    • Inside the mydirectory, create 1 or 2 text files with a .txt extension using the touch command (e.g., touch file1.txt).

  • Add Text to the Files:

    • Paste or write text of your choice into the text files using the cp or echo command.

  • Rename the File:

    • Rename one of the text files to a name of your choice using the mv command.

  • Count and List Words by Frequency:

    • Count the words in the renamed file and list them by frequency using the following pipeline:
      tr '[:space:]' '[\n*]' < renamed_file1.txt | sort | uniq -c | sort -nr > frqList.txt

  • Create a Word Cloud:

    • Use the list created in frqList.txt to generate a word cloud.
    • Refer to the word_cloud GitHub repository for instructions on how to create a word cloud.

  • Save the Word Cloud Image:

    • Save the generated word cloud image in either PDF or PNG format.

  • Submission:

    • Submit the following items:
      • The word cloud image (in PDF or PNG format)
      • The frqList.txt file containing the word frequency list
      • The list of commands you used to come up to the solution
