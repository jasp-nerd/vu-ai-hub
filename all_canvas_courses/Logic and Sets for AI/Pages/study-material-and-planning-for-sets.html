How to study and prepare

  • For every lecture there are slides and recorded videos.
  • Before coming to class watch the video lecture for that day and read through the slides. In class we will go through a selection of the material on the slides and combine the theory with additional examples and questions.
  • After class go over your notes and write down the question you have about the material and parts you don't understand.
  • Prepare the exercises.
  • At the tutorial/seminar/recitation you can ask questions about homework problems and additional questions you have about the material.

Errata in the Lecture Notes

Unfortunately, there are errors in the Lecture Notes. The most important ones are listed here:

  • Chapter 3: The definition of the Lexicographic order on page 46 is incorrect. The first inequality on the right should be a strict inequality. See the slides for the correct definition.
  • Chapter 3: The claims made in the very last two sentences of the chapter (before the exercises) are incorrect: as is proved in the slides, if a partially ordered set has a largest element (a maximum), that largest element is the only maximal element. Of course, an analogous result holds for smallest and minimal elements.
  • Chapter 5: What the Lecture Notes call the range of a function is (nowadays) usually called the codomain. That is, for a function f: A→B, the set A is the domain and the set B is the codomain.
  • Chapter 5: What the Lecture Notes call the image of a function is more commonly called the range. That is, the range of a function f is defined in most modern texts as the set of all actual output values of the function. We will use the term range in this meaning in the lecture and the exercises, and we will denote the set of all actual output values of the function f as Rf.
  • Chapter 6: orderingsprinciple is not a correct English word. The correct term here is well-ordering principle.
