Dear students,

welcome to the Logic and Set course! We will start with the first lecture tomorrow at 9am in MF-FG1. Please make sure to come! If for some reason, you are not able, there are also videos provided here on the canvas page. Some of you will have already had a look at the information on this page - if you haven't, it might be a good idea to do that now! In particular, you should decide on which working groups to join. Every student should attend 2 working groups every week - one on logic happening in the first half, and one on sets happening in the second half of the week. There are different slots for each group, so see which ones fit your schedule the best (pro-tip: joining a working group with less students can be a good idea, since you can discuss your questions easier with the teaching assistant).
