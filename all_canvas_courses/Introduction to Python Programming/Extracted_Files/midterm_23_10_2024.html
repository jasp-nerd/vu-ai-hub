Task 3. String Cleaning (15 points)¶

Let's assume that you're managing a database, and your database is storing customers' names. However, because of the way we use these names, they must follow specific rules.

For this exercise, you have to create a function called standardize_name that takes a name as input and checks if the name complies with the rules. If the name does not comply with the rules, it must “clean” the name to make sure it complies. This function takes as input a string with a name and must return the changed name when it does not follow the naming rules, or the original name, otherwise.

The rules for the names are:

  • Names (only the first letter in the first name) must start with capital letter. For example, anne frank should be Anne_frank.
  • All other letters in the name must be lowercased.
  • Only alphabetical characters are allowed in the name, any other letters must be deleted (e.g., #, *, + %).
  • Spaces and tabs are not allowed; they must be changed for underscores (_). For example, Python course must be changed to Python_course).
  • Names cannot be longer than 40 characters, longer names will lose their extra letters.

Hint:

  • Python strings have a function called.isalpha() that returns True is all the characters in the string are alphabetical characters, False, otherwise.
  • In Python you can use \t to identify tabs.

Example:
Input:

name = "python3 cOUrse"

Output:

Python_course

Input:

name = "R@#o$n$a*ldo L#@u$i@s N#a@z@a##ri@@o d#e L#@i!m!a"

Output:

Ronaldo_luis_nazario_de_lima
