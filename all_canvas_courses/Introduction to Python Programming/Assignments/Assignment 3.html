This assignment is meant to be developed individually.  You can find a zip file with the contents of the assignment:  assignment_3.zip

To start with the assignment please follow the next steps:

  • Save the file in a specific location on your computer. 
    • !! If you are running python from an environment, please save the assignment zip in the folder of your environment. You can find it under Anaconda3 > envs > [your environment]. 
  • Extract the zip in this place.
  • Read the README.md file, all instructions are contained here. Add your name and VUNet ID in this document.
  • Read the pytest.md file for information on checking your work.
  • Implement all your solutions in the books_types.py file in the books folder. 

All other files like __main__.py, books_utils.py and GUI.py are not necessary for you to run or look at for this assignment.

 

To hand it in:

  • Create a zip file containing the README.md file and the books_types.py file with the name [vunetID]_assignment3 and hand this in here.
    • eg. abc123_assignment3.zip
