We are reaching the end of the course. That means, that next week will be dedicated to finishing up the project and preparing for the exam. Please note the following:

Plan your time wisely so that the two do not clash. As is explained in the syllabus, this is the absolute last moment we can put the deadline, so there will be no extensions.
