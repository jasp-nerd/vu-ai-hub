Dear all,

Next week we will start the course Machine Learning. There will be plenty of time in the first week to find your feet, but there are two things we ask you to take note of now.

First, don't expect to show up to the first lecture and to be told how the course works and what to do. That's how things normally go, but it doesn't work for us, because you won't all fit in a single lecture room. For that reason, we will not explain how the course works in the first lecture. You will have to read about that on Canvas and ask any questions on the discussion board. Please start with this video and annotated slides.

The lecture can be attended online over zoom, or in person. If you are confident you understand everything from the videos and slides, you don't have to attend the lecture.

Second, there are some topics that we expect you to be familiar with. The main ones are linear algebra, calculus, and probability. The preliminaries page will give you an overview of what you need to know. Please have a look; we recommend skimming the page now and making a note of anything that's new. It's fine if there are things you're not familiar with, but it is your responsibility to catch up. There is some time reserved for this in the first week.
