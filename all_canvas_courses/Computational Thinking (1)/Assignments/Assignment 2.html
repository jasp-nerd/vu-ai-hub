    Hint: for instance, if the user has given the following inputs:

  3. New drug therapy

    A hospital is conducting a clinical trial of a new drug therapy for arthritis. However, only patients who are over 65 years old may participate in the trial and receive the new drug. When a patient is registered for the new therapy, their year of birth needs to be put into an online database, which calculates automatically if the patient is indeed over 65. If they are over 65, the software outputs: “Thank you, patient registered.”, but if they are not, it outputs an error message. If the birth-year is smaller than 65, it can be input again as long as it is not given correctly. Implement this feature of the database in Python, making sure that it may be used in any year.

    Hint: to ensure that the user has infinite opportunities to correctly give the birth-year, you can use a while loop. To ensure that the program can be used in any year, you can use Python’s datetime module instead of hard coding the current year into your program.
