  1.  Automatic inventory system 

    A home decor store is implementing an automatic inventory system. The system registers new wares arriving to the store every Monday. Each week, there is a different selection of wall tapestry colors available. On a given week, the following colors arrive in the Monday shipment:

    mustard, salmon, azure, ivory, sage, lilac

    1. Since there is only a limited selection of colors at a time, the system can safely use bubble sort. Sort the above list using bubble sort and show the intermediate steps. Why would bubble sort not be the best option if the list of colors was much longer? What algorithm(s) could be more suitable in that case?
    2. Customers can check on the store’s website what colors are available on the current week. Find the color ivory from the sorted list using binary search and show the steps of iteration.


  2. Waiting list for liver transplant

    A hospital keeps a waiting list for patients who need a liver transplant. In the list, the patients are marked with their last names and the number of weeks that they have been waiting. Taking the sample list below, implement a Python program which sorts this list, so that the patients who have been waiting longer are at the front of the list. If two patients have been waiting for the same number of weeks, they should appear in alphabetical order.

    (Johnson, 9), (Smith, 2), (Perry, 4), (Allison, 8), (Bradley, 1), (Tucker, 9)

    Hint: you can use the lambda function in Python.

  3. Automatized system for receptors

    In a medical laboratory, scientists are developing an automatized system, which reports the density of different receptors on a cell’s surface from a tissue sample. In the report, the receptors are listed from lowest to highest density. Seven receptors (marked as A, B, C, D, E, F, G) have the following density expressed in units used by the system:

    A: 17, B: 52, C: 4, D: 42, E: 48, F: 35, G: 17

    Sort these receptors into the order in which they appear in the report using merge sort. Use the tree notations to show the intermediate steps.



  4. Merge sort or quicksort?

    A database management system is a software which is designed to operate and optimize databases. In one such system, the user has the option to sort rows of tables in the database based on a given column in the table. Since some database tables can be extremely large, this particular system is cautious and decides whether to use merge sort or quicksort in the following way: it calculates the worst-case sorting time for both algorithms and chooses merge sort if it is at least 100 times faster than quicksort in the worst-case scenario.

    Implement this decision step in a Python program: your program should ask for the number of rows in the table as input and display the calculating times along with the name of the chosen sorting algorithm as output based on the calculation described above.
