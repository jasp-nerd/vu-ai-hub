  1. Amsterdam Public Library 

    The Amsterdam Public Library is implementing a new online catalogue, which is aiming to make search faster. In the catalogue, the books are stored in an alphabetical order. Let us suppose that the library has the following books of American literature in their catalogue:

    1. The Catcher in the Rye
    2. East of Eden
    3. The Goldfinch
    4. Gone with the Wind
    5. Grapes of Wrath
    6. The Great Gatsby
    7. Little Women
    8. Of Mice and Man
    9. The Scarlet Letter
    10. To Kill a Mockingbird

    (Note that the article “the” is ignored when sorting the books alphabetically.)

    - Which of these books (one or more) would take the most iterations to find with binary search?
    - How many iterations would that mean?
    - Show these iterations for (at least one of) the longest-taking book(s).

     

  2. Septic shock

    A medical database stores the complications associated with different diseases. As septic shock is one of the most dangerous complications, in covid-stricken times, a hospital wants to estimate how many cases of it they may expect over the coming month in order to prepare better. To do this, they use a system which checks each of the diseases in the above-mentioned database to see if they might lead to septic shock. Let us suppose that the complications of pneumonia are stored in the following list:

    [heart_failure, kidney_failure, lung_abscesses, respiratory_failure, septic_shock]

    - What is the level of recursion (i.e., the number of iterations) if we want to look up septic shock with binary search from this list?
    - What would be the level of recursion if we used linear search?

  4. Public health database 

    A public health database stores data about citizens of a town. One type of data records the types of diseases that have been diagnosed by the general practitioner of this town. In this database, the following diseases are recorded:

    [arthritis, chickenpox, diabetes, eczema, influenza, pneumonia, tonsillitis]

    Implement a Python program which asks the user for a disease then uses linear search to check if it is recorded in the database and displays an output message accordingly. Make sure to implement the linear search algorithm explicitly and do not only rely on the built-in in operator in Python.
