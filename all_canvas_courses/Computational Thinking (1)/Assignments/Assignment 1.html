    1. Airline company

      An airline company wants to allow its customers to view ticket prices in different currencies.  Write a program that asks a user where they want to go and which currency they would like to use, then display the appropriate ticket price. It is enough to implement this for three destinations and three currencies (assume the departure is always from Amsterdam - you can find the prices and exchange rates below).

      DUBLIN: 21 EUR

      SEATTLE: 400 EUR

      ISTANBUL: 127 EUR

      1 EUR = 1.09 USD

      1 EUR = 16.14 TRY

      1 USD = 14.70 TRY 

    2. Blood Sugar Level (BSL)

      A health application helps users monitor their blood sugar levels (BSL). One feature allows a user to type in what they would like to have for breakfast, and the app estimates how much that will raise their BSL. Implement a highly simplified version of this program, which asks the user if they would like to have a banana then asks if they would like to have some cereal as well. Afterward, it should ask if the person is diabetic. Finally, the program should output the estimated BSL rise.

      You can use the following information (which is entirely made up for the sake of simplicity):

      • In a healthy person, eating a banana causes a BSL rise of 0.5 mmol/liter, while eating a bowl of cereal results in a 2 mmol/liter BSL rise.
      • In a diabetic person, eating a banana causes a BSL rise of 1.0 mmol/liter, while eating a bowl of cereal results in a 4.0 mmol/liter BSL rise.
      • Eating both types of food simply adds the BSL rises together (e.g., if a healthy person eats a banana and a bowl of cereal, their blood sugar levels would rise by 2.5 mmol/liter).
       

    3. Image recognition system
      A medical image recognition system estimates a patient’s head circumference from the area of the cross-section of their head in an image. Write a program that takes as input an area and outputs a circumference (you can use any suitable unit, such as cm2-cm).

      (Hint: Assume that the cross-section is a perfect circle, of which the area is given and the circumference needs to be calculated.)

    4. Scheduling rehearsals 

      The national theater uses a scheduling system for a ballet rehearsal, where ballerinas perform duets. There are 6 ballerinas: Andi, Benita, Chloe, Doris, Evelyn, Fatima. They dance in the following duets:

      Andi - Benita

      Evelyn - Doris

      Andi - Evelyn

      Benita - Chloe

      Doris - Andi

      Fatima - Benita

      Chloe - Evelyn

      Benita - Doris

      Doris - Fatima

      Fatima - Evelyn

      For time efficiency reasons, the rehearsal needs to be scheduled with a time slot for each duet in such a way that, when changing from one rehearsal to the next, one of the dancers can remain on stage for the next rehearsal. However, no ballerina may dance more than twice in a row to avoid risk of injury. 

      For example, when Andi and Evelyn have the first rehearsal slot, one possible duet to follow would be Chloe and Evelyn (so that Evelyn could stay on stage).

      Which ballerina cannot be in the first duet regardless of what schedule the system finally comes up with?
